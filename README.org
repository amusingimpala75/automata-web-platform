Generate a =.env= by running

#+begin_src bash
echo "AUTOMATA_WEB_PLATFORM_PEPPER=$(head -c 32 /dev/urandom | base64)" >> .env
echo "AUTOMATA_WEB_PLATFORM_KEY=$(head -c 32 /dev/urandom | base64)" >> .env
#+end_src

The default setup creates a user =admin= with password =admin=. Please reset this immediately. Additionally, you will probably want to elevate the admin to actual admin privileges, use =sqlite3= to do that (=UPDATE users SET admin = 1 WHERE username = "admin"=)
